# Collectors API

Бэкенд-сервис для платформы коллекционеров.  
Позволяет пользователям вести учёт своих коллекций, выставлять предметы на обмен или продажу, общаться через чаты и оставлять отзывы.

---

## 🚀 Стек технологий

- **Node.js** + **Express**
- **PostgreSQL** + **Sequelize** (ORM)
- **JWT** (access + refresh токены)
- **Passport.js** (Google, Яндекс OAuth 2.0)
- **Socket.IO** (чаты в реальном времени)
- **Bull** + **Redis** (очереди для отправки писем и обработки фото)
- **Meilisearch** (поиск объявлений и пользователей)
- **Jest** + **Supertest** (тестирование)

---

## 📦 Основной функционал

### 👤 Пользователи
- Регистрация по **email** или **номеру телефона**
- Вход по логину/email/телефону
- OAuth 2.0 (Google, Яндекс)
- Верификация email
- JWT-аутентификация с refresh-токенами

### 📂 Коллекции и предметы
- Учёт коллекций пользователя
- Добавление предметов в коллекцию
- Загрузка фотографий (до 5 шт. на предмет)
- Состояние предмета (mint, excellent, good, fair, poor)

### 📢 Объявления (Listings)
- Создание объявлений о продаже или обмене
- Модерация объявлений (ADMIN / MODER)
- Поиск с фильтрацией (по цене, типу, категории, наличию фото)
- Авто-индексация в Meilisearch

### 💬 Чаты (Deals)
- Обсуждение сделок в реальном времени
- WebSocket (Socket.IO)
- История сообщений с пагинацией
- Отметка о прочтении

### ⭐ Отзывы (Feedbacks)
- Оставление отзыва после завершения сделки
- Оценка от 1 до 5
- Рейтинг пользователя автоматически обновляется

### 🔖 Закладки (Bookmarks)
- Сохранение интересных предметов в закладки

### 🔐 Роли
- **USER** — базовый пользователь
- **MODER** — модерация объявлений
- **ADMIN** — управление пользователями и категориями
- **GARANT** — работа со спорными сделками (опционально)
